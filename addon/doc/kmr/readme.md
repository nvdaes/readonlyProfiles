# Profîlên TenêXwendinê

* Nivîskar: Noelia Ruiz Martínez

Dema ku ev pêvek çalak be, profîlên mîhengkirinê dê bixweber neyên tomarkirin.

Ji bo tomarkirina mîhengê heyî li profîla herî dawî NVDA+shift+p bikirtînin.

Ev ferman dikare ji pêşeka NVDA, jêr-menûya Tercîhan, diyaloga Jestên Têketinê û kategoriya Mîhengkirinê were guhertin.
